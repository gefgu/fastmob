# Release notes

Release notes document user-visible changes to Fastmob. The documentation site
describes the current release; use the entries below to plan upgrades and find
migration notes for renamed or removed APIs.

| Version | Highlights |
| --- | --- |
| [v0.2.0](v0.2.0.md) | Trajectory hierarchy, new preprocessing algorithms, models, network/social analysis, Arrow-only Rust bindings. |

## Upgrade policy

Breaking changes, deprecations, and migrations are called out in the relevant
release entry. Pin `fastmob` to a released version in reproducible workflows,
and consult these notes before upgrading a minor version.
