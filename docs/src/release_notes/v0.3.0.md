# v0.3.0

Released 2026-09-18.

- **STVD**: a parallel EMD cost matrix, a Rust `mean_area_volume` kernel that
  scales to 100M-row inputs, and a sparse H3-candidate-graph Sinkhorn path.
  The sparse path is now the only production path for `stvd_emd`, so the
  `wass` runtime dependency is gone.
- **Contact networks**: RECAST event graphs and kernels are shared between raw
  contact networks and contact diagnostics.
- H3 cell centroid conversion is exposed.
