# v0.3.4

Released 2026-10-28.

- **Fixed:** [`common_part_of_commuters_distance`](../reference/measures/evaluation.md) divided by
  the sum of the distances instead of the number of trips, so it returned about `1 / mean distance`
  instead of 1 for identical distance distributions. Results from earlier releases are wrong and
  should be recomputed.
- **Fixed:** [`load_geolife`](../reference/data.md#fastmob.data.load_geolife) returned files cached
  by earlier calls with a different `users` or `max_trips_per_user`; files are now cached per
  selection.
- **Fixed:** [`interpolate_at`](../reference/trajectory.md) accepts a pandas `DatetimeIndex` or any
  iterable of timestamps for `at`, instead of failing with an array error.
- The [Learn](../learn/index.md) section is now eighteen notebooks and concept pages in six
  chapters. Every notebook runs from a fresh environment on Python 3.12 or newer and uses public
  data; each Reference entry links to the notebook section that runs it, and the Reference
  catalogues are grouped by task.
- New notebook [Chart your results](../learn/visualize-results.md) draws every `fastmob.vis` chart,
  and the [Visualization reference](../reference/visualization.md) documents all of `fastmob-vis`.
  `fastmob[vis]` now needs `fastmob-vis` 0.1.1, which fixes the generic `ecdf` chart (it did not draw
  in a browser), the generic `bar` tooltips (shown as percentages) and
  `plot_activity_transition_matrix` given the result of `activity_transition_matrix`.
- No breaking changes.
