# v0.3.4

Released 2026-10-27.

- **Fixed:** [`common_part_of_commuters_distance`](../reference/measures/evaluation.md) divided by
  the sum of the distances instead of the number of trips, so it returned about `1 / mean distance`
  instead of 1 for identical distance distributions. Results from earlier releases are wrong and
  should be recomputed.
- **Fixed:** [`load_geolife`](../reference/data.md#fastmob.data.load_geolife) returned files cached
  by earlier calls with a different `users` or `max_trips_per_user`; files are now cached per
  selection.
- **Fixed:** [`interpolate_at`](../reference/trajectory.md) accepts a pandas `DatetimeIndex` or any
  iterable of timestamps for `at`, instead of failing with an array error.
- The [Learn](../learn/index.md) section is now fifteen notebooks and concept pages in five
  chapters. Every notebook runs from a fresh environment, uses public data, and ends with a
  measured run-time table; each Reference entry links to the notebook section that runs it.
- No breaking changes.
