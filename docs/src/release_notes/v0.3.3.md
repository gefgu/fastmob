# v0.3.3

Released 2026-10-27.

- New dataset loaders [`fastmob.data.load_geolife`](../reference/data.md#fastmob.data.load_geolife)
  and [`fastmob.data.load_brightkite`](../reference/data.md#fastmob.data.load_brightkite).
  They fetch only the requested users or rows from the public archives (a few
  megabytes instead of 313 MB for GeoLife), cache the files, and raise an
  error instead of substituting data when a download fails.
- No breaking changes.
