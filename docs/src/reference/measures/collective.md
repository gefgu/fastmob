# Collective Measures

| API | Description |
| --- | --- |
| [`homes_per_location`](#skmob2.measures.collective.homes_per_location) | Return the number of users whose home is at each distinct location. |
| [`mean_square_displacement`](#skmob2.measures.collective.mean_square_displacement) | Return the mean square displacement (km^2) across all users. |
| [`random_location_entropy`](#skmob2.measures.collective.random_location_entropy) | Return the random entropy for each distinct location across all users. |
| [`uncorrelated_location_entropy`](#skmob2.measures.collective.uncorrelated_location_entropy) | Return the uncorrelated entropy for each distinct location across all users. |
| [`visits_per_location`](#skmob2.measures.collective.visits_per_location) | Return the total number of visits for each distinct location. |
| [`visits_per_time_unit`](#skmob2.measures.collective.visits_per_time_unit) | Return the number of trajectory points per time unit across all users. |
| [`od_matrix`](#skmob2.measures.collective.od_matrix) | Compute an Origin-Destination matrix from a trips DataFrame. |
| [`od_metrics_per_area`](#skmob2.measures.collective.od_metrics_per_area) | Compute per-area mobility metrics from a long-format OD DataFrame. |
