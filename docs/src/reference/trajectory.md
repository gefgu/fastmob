# Trajectory

| API | Description |
| --- | --- |
| [`interpolate`](#fastmob.trajectory.interpolate) | Fill gaps in a trajectory by inserting interpolated points. |
| [`interpolate_at`](#fastmob.trajectory.interpolate_at) | Query each user's interpolated position at one or more timestamps. |
| [`trajectory_distance`](#fastmob.trajectory.trajectory_distance) | Compute a similarity/distance metric between two trajectories. |
