# How-to guides

These short recipes take you from a concrete task to a working Fastmob call.
They use small, deterministic inputs; the API reference remains the complete
parameter contract.

| Task | Start here |
| --- | --- |
| Inspect a minimal trajectory | [Start with a trajectory](analyze-a-simple-trajectory.md) |
| Adapt your schema or backend | [Columns and backends](use-custom-columns-and-dataframe-backends.md) |
| Remove noise and split movement | [Clean and segment trajectories](clean-and-segment.md) |
| Turn pings into places | [Create staypoints and locations](staypoints-and-locations.md) |
| Describe individuals and populations | [Measure people and populations](individual-and-collective-measures.md) |
| Work with roads, routes, and GPS traces | [Route and map-match trajectories](network-analysis.md) |
| Fit laws and compare results | [Fit and evaluate mobility results](fit-and-evaluate.md) |

!!! tip "Use the right level of detail"

    Recipes show the shortest supported route to a result. For accepted
    columns, return schemas, edge cases, and all options, follow the API links
    on each page.
